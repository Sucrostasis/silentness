# 玩家流程剧本

## 第一幕：进入档案馆

**场景**：玩家打开首页 `index.html`

**视觉感受**：
- 一个看起来像 2010 年代初的档案类网站
- 低饱和度的灰白背景
- 简单的表格和边框
- 没有现代网站的动画效果
- 页脚有版权信息和极小的虚构声明

**玩家行动**：
- 浏览网站标题和简介
- 看到"静默回声声学档案馆"的名称
- 阅读"虚构声音资料数字保存计划"的副标题
- 注意到导航栏：首页、档案检索、关于、联系
- 看到一个搜索框和推荐馆藏列表

**线索埋设**：
- 页脚有一行极浅的文字："校验码 04-12-0315"（几乎不可见）
- HTML 源码注释中包含：`<!-- archive checksum: U0VMRUNULzEvMzk5MQ== -->`
- 系统状态指示灯是绿色的

**玩家心理**：
- "这看起来像一个普通的档案网站"
- "也许是某个研究项目？"
- "没有什么特别的..."

---

## 第二幕：索引异常

**场景**：玩家在 `archive.html` 搜索异常关键词

**触发条件**：
- 搜索词包含以下任意一个：
  - "静默"
  - "回声"
  - "7742"
  - "空白"
  - "北岭"

**系统反馈**：
- 搜索结果区域短暂显示"索引校验失败"（红色提示框）
- 页面底部出现一行浅灰色文字："请验证会话完整性"
- 这行文字没有明显链接样式，但鼠标悬停时颜色会变深

**玩家行动**：
- 点击那行浅灰色文字
- 或者查看浏览器控制台（Console）

**线索输出**：
- Console 中显示：`checksum required: ts=19870412T031500Z`
- 搜索结果表格中插入一条隐藏记录：
  - 编号：#3991
  - 标题：未命名环境音片段
  - 年份：1987
  - 该行的 HTML 包含属性：`data-ts="19870412T031500Z"`

**玩家心理**：
- "这个搜索结果有点奇怪..."
- "为什么会有'索引校验失败'？"
- "这行小字是做什么的？"
- （如果打开控制台）"Console 里有东西！"

---

## 第三幕：隐藏条目

**场景**：玩家拼接 URL 访问隐藏详情

**玩家行动**：
- 根据线索拼接 URL：
  ```
  item.html?id=3991&ts=19870412T031500Z
  ```
- 或者点击搜索结果中的 #3991 链接（已自动包含参数）

**页面内容**：
- 显示正常的档案详情页
- 包含音频播放器占位
- 技术备注等标准信息

**关键变化**：
- 页面底部额外显示一个链接：
  ```
  维护索引 / 回声通道
  ```
- 该链接指向 `hidden/maintenance.html`
- 链接颜色较浅，不显眼

**玩家心理**：
- "这个页面看起来正常，但多了一个奇怪的链接..."
- "'维护索引'是什么？"
- "点进去看看"

---

## 第四幕：维护通道

**场景**：玩家进入 `hidden/maintenance.html`

**视觉风格**：
- 黑底灰字的维护后台风格
- 无导航栏
- 看起来像遗留系统

**页面内容**：
```
维护索引

回声通道已关闭。
如需继续，请验证归档序列。

[输入框] [验证按钮]
```

**玩家行动**：
- 尝试输入各种内容
- 可能回到之前的页面寻找线索

**线索来源**：
- 回到首页查看源码
- 发现 HTML 注释中的 Base64：
  ```html
  <!-- archive checksum: U0VMRUNULzEvMzk5MQ== -->
  ```
- 使用在线工具或 Console 解码：
  ```javascript
  atob('U0VMRUNULzEvMzk5MQ==')
  // 返回："SELECT/1/3991"
  ```

**正确答案**：
- 在输入框中输入：`SELECT/1/3991`

**成功反馈**：
- 显示绿色文字："通道已验证。"
- 出现链接："进入终端"
- 链接指向 `terminal.html`
- localStorage 设置：`sesa_maintenance_verified=true`

**错误反馈**：
- 显示："当前请求已转入低优先级队列。"
- HTML 源码注释中暗示：
  `<!-- hint: checksum was printed on the front page footer -->`

**玩家心理**：
- "这是个密码？从哪里找？"
- （查看源码后）"这个 Base64 是什么？"
- （解码后）"SELECT/1/3991... 试试这个！"
- "成功了！有个新链接！"

---

## 第五幕：终端监听

**场景**：玩家进入 `hidden/terminal.html`

**视觉风格**：
- 黑色背景
- 绿色等宽字体
- 类似老式终端界面

**初始输出**：
```
SESA MAINTENANCE TERMINAL
Build 0.9.4
Last session: 2014-06-19
Type help for available commands.

>
```

**玩家行动**：
- 输入 `help` 查看可用命令
- 逐个尝试命令探索功能

**关键命令序列**：

1. `help` - 查看命令列表
2. `status` - 查看系统状态
   ```
   index: read-only
   tape_drive: offline
   echo_channel: suspended
   last_operator: unknown
   pending_object: #7742
   ```
3. `scan` - 扫描低频
   ```
   Scanning low-frequency bands...
   Found irregular pulse at band 7742.
   Signal is silent but structured.
   ```
4. `list` - 列出磁带
   ```
   #7741 normal
   #7742 restricted
   #7743 empty
   ...
   ```
5. `open 7742` - 尝试打开（被拒绝）
   ```
   Access denied.
   Reason: public hearing not authorized.
   ```
6. `frequency 7742` - 分析频率
   ```
   Band 7742 accepted.
   Echo pattern detected.
   Do you want to decode? y/n
   ```
7. `y` - 确认解码
   ```
   Decode session initialized. Type "decode" to proceed.
   ```
8. `decode` - 执行解码
   ```
   Decoding...
   Fragment recovered:
   "Do not make it audible."
   Operator H. last note incomplete.
   
   Object #7742 can now be viewed.
   Return to item.html?id=7742
   ```

**解锁完成**：
- localStorage 设置：`sesa_7742_unlocked=true`
- 首页状态灯变为琥珀色并闪烁

**玩家心理**：
- "这是个命令行界面！"
- "status 显示#7742 是待处理对象..."
- "list 显示#7742 是受限的"
- "frequency 7742 让我解码..."
- "'Do not make it audible.' 这句话什么意思？"
- "它说可以访问 item.html?id=7742 了！"

---

## 第六幕：选择

**场景**：玩家访问 `item.html?id=7742`

**前置条件**：
- localStorage 中 `sesa_7742_unlocked=true`

**页面内容**：
```
档案编号 #7742

标题：低频回声片段（未分类）
年份：1987
时长：00:07（循环）
介质：磁带
状态：受限 - 已解锁

技术备注：
- 每 7 秒出现一次低频脉冲
- 波形呈对称折叠
- 频谱图中形成类似走廊结构
- 与北岭实验广播站停电记录时间同步

志愿者备注：
"不要把它转成可听见的。" — Operator H.

你决定：
[公开档案] [继续静默]
```

**玩家行动**：
- 阅读所有信息
- 理解两个选择的含义
- 做出决定

**玩家心理**：
- "这就是那个神秘的#7742..."
- "'不要把它转成可听见的'——何默留下的警告"
- "我应该公开它还是保持静默？"
- "公开可能会揭示真相，但也可能带来未知后果"
- "静默是尊重警告，但也意味着永远无法知道答案"

---

## 第七幕：结局

### 结局 A：公开档案

**跳转**：`endings/public.html`

**内容**：
```
公开档案

你选择公开 #7742。

系统开始转码。
低频信号被提升到可听范围。

[音频播放器占位]

档案编号 #7742 已从封存层移出。
它现在可以被检索、播放、复制、传播。
没有人知道它最初是什么。
但从这一刻开始，它将作为回声存在。

公开并不代表安全，只是代表不再沉默。

[返回首页]
```

**余韵**：
- 玩家选择了揭示未知
- 声音被释放，但后果未知
- 也许有人会听到不该听的东西
- 也许真相根本不存在

### 结局 B：继续静默

**跳转**：`endings/silent.html`

**内容**：
```
继续静默

你选择继续静默。

系统将 #7742 重新标记为不可检索。
所有临时解码记录被清除。

对象已封存。
索引恢复正常。
没有声音被播放。

有些档案被保护，有些档案被阻止。
静默也是一种决定。

[返回首页]
```

**后续效果**：
- localStorage 中 `sesa_7742_unlocked` 被清除
- 状态灯恢复绿色
- 一切回到原点

**余韵**：
- 玩家选择了尊重警告
- 秘密继续保持秘密
- 但好奇心可能永远不会消失
- 也许下一个来访者会做出不同选择
