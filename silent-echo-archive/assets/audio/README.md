# 音频占位文件说明

## 当前状态

本目录中的音频文件目前是占位文本文件。由于技术限制，无法直接生成真实 MP3 二进制数据。

## 占位文件列表

### silence_01.mp3
- **用途**：普通档案试听占位
- **建议时长**：7 秒
- **建议内容**：接近静默的白噪声

### silence_02.mp3
- **用途**：长音频占位
- **建议时长**：14 秒
- **建议内容**：带轻微底噪的空白磁带

### echo_fragment.mp3
- **用途**：#7742 关键音频
- **建议时长**：7 秒（可循环）
- **建议内容**：低频脉冲，极弱

## 如何替换为真实音频

### 方法一：使用 Audacity 生成

1. 下载并安装 Audacity（免费开源）
   https://www.audacityteam.org/

2. 生成 silence_01.mp3：
   - 生成 > 噪声 > 白噪声
   - 效果 > 放大 > 调整为 -40dB
   - 文件 > 导出 > 导出为 MP3

3. 生成 echo_fragment.mp3：
   - 生成 > 啁啾... > 频率 20-40Hz
   - 效果 > 颤音 > 频率 0.14Hz（每 7 秒一次）
   - 效果 > 放大 > 调整到可听边缘
   - 导出为 MP3

### 方法二：使用在线工具

1. 访问在线音频生成器
2. 选择噪声类型和参数
3. 下载生成的 MP3
4. 放入此目录

### 方法三：使用现有素材

如有合法授权的环境音素材：
1. 剪辑为适当长度
2. 转换为 MP3 格式
3. 重命名为对应文件名
4. 放入此目录

## 保持占位的影响

如果保持占位文本文件：

- 网页不会崩溃
- 音频播放器会显示错误
- 浏览器控制台会有加载失败警告
- 页面会显示"音频不可用。档案可能已损坏。"
- ARG 流程不受影响

这实际上符合档案馆"损坏/丢失"的主题设定。

## 文件格式要求

- **格式**：MP3 (MPEG-1 Audio Layer 3)
- **比特率**：128 kbps（足够）
- **采样率**：44.1 kHz
- **声道**：单声道或立体声均可

## 文件大小建议

- silence_01.mp3: < 100 KB
- silence_02.mp3: < 200 KB
- echo_fragment.mp3: < 100 KB

## 测试方法

替换后：
1. 刷新包含音频播放器的页面
2. 点击播放按钮
3. 确认声音正常
4. 检查浏览器控制台无错误
